Why these letters aren't published here

The City currently publishes these letters as submitted, including each signer's home address, personal email, and/or phone number. This demonstration takes a different approach: rather than reproduce that contact information alongside a name, it lists letters by number only and omits their content. Each letter's page includes a sample showing the format a letter could take instead.

One of the 13 letters in the source materials was also named in a way that identified the sender (their name appeared in the file name itself). That letter has been left out of this list entirely, rather than merely anonymized, since the name is already part of the record before any content redaction would even begin.
